      B.Tech Major Project · Department of Computer Science & Engineering

      Neon Pulse: Sentiment & Emotion Analysis of Code-Mixed Hinglish Text using a Hybrid Rule-Based and Machine Learning Approach

      Abstract — Social media users in India routinely mix Hindi and English in Roman script ("movie acchi nahi thi but songs mast the"). Standard English sentiment tools fail on such code-mixed text because they neither recognise Hindi vocabulary nor its post-positional negation. Neon Pulse addresses this with (i) a Hinglish-aware lexicon with spelling-variant normalisation, Hindi negation handling and intensifiers, (ii) machine-learning classifiers (Naive Bayes, Logistic Regression) trained on a labelled Hinglish corpus, and (iii) a hybrid model that fuses both. All engines are compared using stratified k-fold cross-validation. The system also detects eight emotions and provides batch, comparative and longitudinal analytics through an animated, fully client-side dashboard that preserves user privacy.

      Algorithm

      1. Tokenise text into words, emoji, emoticons and punctuation.
      2. Normalise Hinglish spellings (bahot/bhot → bahut) and look up valence v ∈ [−4, +4] in the English + Hinglish lexicon.
      3. Multiply by intensifier factor (very ×1.5, slightly ×0.5).
      4. Negation: English pre-negation window ("not good") and Hindi post-negation look-back ("accha nahi"), both ×−0.75.
      5. Halve weight before "but / lekin / magar", amplify after it (×1.5).
      6. Boost CAPS (×1.3) and exclamation marks (up to +32%).
      7. Normalise: compound = x / √(x² + 15) → range −1 … +1.
      8. Label: ≥ +0.05 positive, ≤ −0.05 negative, otherwise neutral.
      9. Hybrid: P = 0.4·Prules + 0.6·PNaiveBayes, label = argmax.
